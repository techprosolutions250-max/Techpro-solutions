What does web hosting actually do?

A website is made of files, images, code and data. Web hosting is the service that stores those files on a server and makes them available when someone visits your domain.

Domain name

The address people type, such as example.com. A domain is registered separately from hosting in many cases.

Hosting

The server space and services that keep your website available online. Compare storage, traffic limits, support, security and renewal prices.

Website files

The pages, images and code that make up the site. Keep a backup so you can recover your work.

Before you pay

Check the renewal price, refund policy, backup options, SSL availability, support hours and whether email is included.
