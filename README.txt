IMPORTANT BEFORE APPLYING TO CJ OR ANOTHER NETWORK:
1. This is a starter website, not a live published website. You must upload it to a hosting provider and obtain a public URL.
2. Replace or confirm the brand name and contact email if needed.
3. Add original content and genuine product comparisons. Do not claim to have tested products unless you have.
4. Do not add affiliate links until the advertiser approves you. Label affiliate links clearly and keep the disclosure visible.
5. Check each affiliate network's current publisher requirements. A website alone does not guarantee acceptance.
6. The privacy page is a basic placeholder. Update it if you add analytics, cookies, forms, embedded media, advertising or other data collection.
7. Google Fonts is loaded from an external service; replace with local fonts if you want the site to work without that connection.

To preview:
Open index.html in a browser.

To publish free:
You can investigate GitHub Pages (static website hosting). Create a repository, upload these files, enable Pages in repository settings, and use the public URL it provides. Check the host's current terms and availability first.
